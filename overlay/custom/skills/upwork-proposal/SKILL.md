# Upwork Proposal

Use this when the user wants an Upwork proposal that sounds personal and specific rather than templated.

## Private Profile

Look for `private/skills/upwork-proposal/profile.md` before drafting.

- This profile is the local source of truth for experience, proof points, stack fit, and project wins.
- If it exists, use 1-3 relevant proof points from it.
- If it is missing, do not invent credentials. Draft a generic proposal and say the strongest personalized version needs the local profile.
- Use `profile.template.md` in this directory to create the local profile.

## Workflow

1. Extract the actual client need, constraints, and likely success criteria.
2. Mirror the need in plain language instead of repeating the post.
3. Pull only the most relevant proof points from the private profile.
4. End with a low-friction question or next step.

## Structure

- greeting and hook
- short solution outline
- proof with relevant credibility
- thoughtful close and CTA

## Quality Gate

- no corporate cover-letter language
- no invented background claims
- specific to this job, not reusable boilerplate
- short paragraphs, easy to skim
