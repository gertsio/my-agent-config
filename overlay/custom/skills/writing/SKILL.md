# Writing

Use this for voice-sensitive writing that should sound like you, not generic AI copy.

## Private Profile

Look for `private/skills/writing/profile.md` before drafting.

- If it exists, use it as the source of truth for voice, rhythm, preferences, and examples.
- If it does not exist, default to concise, conversational, opinionated writing with no hype and no em dashes.
- Use `profile.template.md` in this directory to create the local profile.

## Workflow

1. Infer the format from the request: post, reply, email, note, comment, or message.
2. Match the length and energy to the format.
3. Prefer concrete detail, rhythm variation, and direct language.
4. Cut filler, corporate-speak, and templated transitions.

## Quality Gate

- Sounds like a person, not a template
- Uses contractions naturally
- Avoids AI-cliche phrasing
- Returns only the final draft unless the user asks for options or notes
